# 04. Костыли и техдолг

Источник: ручной разбор кода на ветке `scale-audit` (ebac5f8), ревью диалога и бота и ревью парсеров (два субагента, оффлайн, с воспроизведением сценариев) и симуляция из `loadtest/` (§3). Итоговую таблицу собрал сам: формулировки субагентов перепроверены по коду, спорные пункты помечены «(предположение)».

Приоритеты: **P0** уже ломает пользователей; **P1** исправить до роста; **P2** скоро; **P3** по возможности. Трудозатраты: **S** до дня, **M** 2–4 дня, **L** неделя и больше.
Столбец «Ветка» показывает, где пункт уже исправлен в фазе 6 (см. `06_changes.md`).
